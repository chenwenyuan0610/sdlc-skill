# Release Handoff — Phase Exit Criteria 詳細清單

每個步驟的具體檢查項，全部確認才算 Phase 7 完成、可以進入 Phase 8。

## 步驟 29 部署前檢查
- 環境變數/憑證/資料庫 migration 逐項確認就緒
- 檢查清單狀態為「通過」，不是「大致準備好了」

## 步驟 30 部署到測試環境（staging）
- staging 已實際運行並可存取驗證
- 部署動作由使用者手動觸發，Lead 沒有代為執行

## 步驟 31 部署到正式環境（production）
- production 已實際上線
- 部署動作由使用者手動觸發，Lead 沒有代為執行

## 步驟 32 上線後煙霧測試
- 核心功能路徑已快速驗證（綠燈才算過，不是「應該沒問題」）
- 若煙霧測試不過，已明確記錄要退版還是修正

## 與既有機制的關係
本階段是新內容，不涉及分工問題；部署動作一律人工手動觸發是不可越過的安全紅線，不是待補的既有工具問題。
